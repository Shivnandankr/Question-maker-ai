# Question Maker AI

A lightweight Hindi mathematics practice app designed for competitive exam preparation and school-level maths revision.

## Overview

This project is a static web application that helps students:

- choose an exam category
- search topics by chapter name
- browse maths chapters by subject area
- practice MCQ-based questions with answer checking
- review explanations and solutions
- take a short test in practice mode

The interface is bilingual-friendly and built around a Hindi learning experience for students preparing for SSC, Railway, Banking, Bihar competitive exams, and school mathematics.

## Features

- Exam selection dropdown
- Search-based chapter discovery
- Subject-wise category cards
- Topic lists with chapter navigation
- Question generation for arithmetic and maths concepts
- Multiple-choice answers with instant feedback
- Step-by-step solution display
- Practice test mode with score tracking
- Responsive single-page layout

## Included Topic Areas

## Run Locally

Open the project in a browser directly:

1. Clone the repository
2. Open `index.html` in your browser

Or serve it locally with any static web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
